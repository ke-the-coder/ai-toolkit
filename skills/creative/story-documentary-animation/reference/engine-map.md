# Engine map: `template/story-engine.html`

The template is the first approved page, 盘古开天辟地 (`example/01-盘古开天辟地-无录音.html` is that page without its recordings), with these changes:
- the recordings are removed;
- the recordings variable is `window.STORY_REC` (example 01 still uses the old name, `window.PANGU_REC`);
- one `fastStep(dt)` function is added: it runs one frame without drawing, and the debug hash and the tools use it;
- **the section-change burst is fixed.**
  - **The bug:** `setSection()` faded out every tracked note from its current `gain.value`. A note queued to start in the next 250 ms still has the default gain of 1, so it faded from full volume, about 30 dB too loud.
  - **The effect:** a +15 dBFS blast (before the limiter) when example 02 went from *grand* into *worry*.
  - **The fix:** `track(g, end, st)` now records each note's start time, and notes that haven't started are set to 0.
  - It depends on timing: a full play-through of example 01 before the fix never blasted (its loudest music at a section change was −4 dBFS). All three examples have the fix.
- **A Latin font for English text:** `.en` (subtitles) and `#lower .l3` (fact-box lines) start with `"Segoe UI","Helvetica Neue",Arial` before `var(--sans)`. With the CJK body font, ’ “ ” were drawn full-width ("didn’ t"). All three examples have it.
- **Timed events on chapter cards:** `runTick` fires a card's numeric `ev` entries (for example `[2.3, 'none', {dim:[0, 1.8]}]`). Word anchors never fire on a card, because `evReady` returns false in the card phase. `stateAt` already replays their third items. Example 03 has this; examples 01 and 02 don't, and none of their cards has events.
- **Delayed tweens start from the current value:** a tween queued with a delay takes its start value when it begins, not when it was queued, so anything that sets the value in between no longer snaps back. Example 03 has this; examples 01 and 02 keep the old behaviour.

Two more built pages sit in `example/` without their recordings, so they're safe to Read and grep. Lift parts from them (catalogues at the end of this file), but still start each new page from the template.
- **Example 02** (`example/02-女娲造人与补天-无录音.html`) is the template plus a human character in robes, a landscape, crowds, weather and more on-screen graphics.
- **Example 03** (`example/03-神农尝百草-无录音.html`) adds a man in a leaf cape and tunic, with a basket, a rock shelter, a body diagram, a record card, a route map, an indoor shop, a book, a relay of generations and a reminder card.

With those exceptions, every line of the template is code that was reviewed working. It's about 2,700 lines and 170 KB, all in one HTML file.

**How to find things:** each section begins with a comment like `/* ================= 时间线 ================= */`. Grep for the Chinese section name; line numbers change as you edit.

**What each label means:**
- **Keep:** reuse it unchanged.
- **Adapt:** reuse it but edit parts of it.
- **Replace:** write it new for each story.

## Cue schema (`CUES`)

```js
{card:'ch1', dur:5.2, mood:'chaos', pal:['day',4], k:{…}}             // chapter card: shown for dur seconds, not spoken
{card:'ch2', dur:5.2, k:{dim:[.92,.8], camX:[-2440,.01,1], …},       // a card may have timed events (seconds only):
 ev:[[2.3, 'none', {dim:[0, 1.8]}]]}                                  //   example 03 dims, cuts the scene at 1 s, then un-dims
{zh:'…', en:'…',               // a narration line (subtitles and voice); must start its own line in the source
 pre:.5,  post:1,  min:2.6,    // seconds of silence before and after speaking; min = shortest length of the cue
 mood:'egg',                   // switch the music section (a SECS key) when the cue starts
 pal:['womb', 5, .5],          // blend to a palette: [name, duration, delay]
 k:{camZ:[1.28, 9, 0, 's'],    // animate a P value: [target, duration, delay, ease]
    pgH:[930, '@', 0, 'stair'],//   '@' = this line's speaking time, '@+1.5' = speaking time + 1.5 s
    camX:['@hx', 2.8]},        //   '@hx' / '@hy+50' = the character's head position (G.head)
 pose:[['kneel', 2.4], ['lie', 3.4, 2.3]],                  // [pose, duration, delay, ease], queued
 ev:[[{zh:'盘古', en:'Pangu'}, 'nameGlow'],                  // fires when the voice reaches that word (either language)
     [0.4, 'impact', {crack:[.3, .25, 0, 'o']}]],            // or 0.4 s into the cue; the optional third item is extra k values
 fx:'tremble',                 // a continuous effect for this cue (the example uses tremble, look, quake)
 call:{zh:'左眼 → 太阳', en:'LEFT EYE → SUN', at:'sun'},     // "X → Y" label placed by calloutAnchor(at)
 on:'keepSky'}                 // ON[name]() runs when the cue starts
```

- **Eases:** `lin`, `io` (the default), `o`, `i`, `s`, `back`, `stair` (grows in 6 steps).
- **Cue order:** a card waits `dur` seconds, firing any timed events on the way (word anchors never fire on a card). A narration line goes pre → speak → post, and speak lasts until the voice or recording actually ends. Picture and voice stay in sync at any speaking speed.
- **Jumping** (←/→ keys or the debug hash): `stateAt(i)` replays every earlier cue's final values. So any new value must be in `P0`, and any new short-lived state in `G` must be reset in `stateAt`.

## Audio chain (`audioInit`)

- **Master:** gain .9 → compressor (−18 dB, ratio 3) → limiter (−3 dB, ratio 20) → speakers.
- **Reverb:** a generated 5.2 s reverb, mixed back in at .8.
- **Music:** `mIn` .68 → `mSec` (fades between sections) → `mDuck` (dips under the voice) → `mMute` (music on/off; fades in when Play is pressed) → master, with a .6 send to the reverb.
  - A level meter sits after `mSec`, before the dip; `duckTick()` reads it.
- **Effects:** `sIn` .8 → master, with a .4 send to the reverb.
- **Voice:** `vIn` 1.1 → master. **Only the recording** goes through here; live browser voices never pass through Web Audio.
- **Timing:** `scoreTick` runs every 40 ms and plans notes 250 ms ahead, in half-beat steps.
- **Sections** (`SECS`) can set:
  - `bpm` and chord progression `prog`;
  - how loud each instrument is: `str`, `choir`, `bass`, `brass`, `spic`;
  - `taiko` (`pulse`, `roll`, `hero` or `drive`) with its level `tv`;
  - `trem`;
  - `flute` (`theme`, `walk` or `lament`) with its level `fv`;
  - `zheng` (`slow`, `arp`, `rise` or `walk`) with its level `zv`;
  - `bells`, `hb` (heartbeat), `whisper`, `boom`, `braam` (a low hit at the start of the section);
  - `silent` (the music stops before a big hit).

## Character rig (for a new character)

- **Joints and poses:**
  - `PDEF` lists joint angles: 0 is up and clockwise is positive, and limbs are measured relative to the body.
  - The joints are `rot`, `neck`, `head`, `sR`/`eR`/`sL`/`eL` (shoulders and elbows), and `hR`/`kR`/`hL`/`kL` (hips and knees).
  - `turn` goes from 0 (facing front) to 1 (side view). `px`/`py` place the character, `lx`/`ly` set where the eyes look, and `ax` is the axe angle.
  - `defPose(name, {...})` defines a pose; wrap it in `mir(...)` to mirror left and right.
- **Movement:** poses blend through a queue. `poseMods()` adds breathing and the `tremble`/`look` effects.
- **Each frame:** `panguUpdate()` computes the joints `G.J` and `G.head`. The `'@hx'` camera targets and `fastStep()` both depend on it. If you rename it, update `fastStep()`, `startCue`, `stateAt`, `render` and the debug hash code.
- **Drawing:** the body is one shape made of capsules (`capsule` and `disc` into `Path2D`). It's filled as a single shape and lit with a rim light from `keyLight()`; hair, beard, face and props are drawn on top.
  - Draw the rim light around the combined outline. When each part was lit separately, lines showed inside the body.
- **Proportions:** `BN`, relative to height `P.pgH`.

## Must change for a new story

1. **Page text:**
   - `<title>`;
   - the `#start` kicker, title and English title;
   - the `#end` source fact and 下一集 line.
2. **Storage prefix:** in `store`, change `'pangu2.'` to a prefix for this story, such as `'s02.'` (example 02) or a short name. Otherwise saved choices carry over between stories.
3. **The story itself:** `CARDS`, `CUES`, `P0`, `G`, `EV`, `ON`, plus new `SFX` and `PAL_SRC` entries.
4. **Drawing:**
   - the scene drawing functions and the draw order in `render()`;
   - the character rig, or remove it and give `G.head` a value if cues use `'@h…'` targets.
5. **`stateAt()`:**
   - the default pose `'curl'`, mood `'title'` and palette `'cosmos'`;
   - `CRK = makeCrack(…)`;
   - the list of `G` values it resets.
6. **`post()`:** the lens flare at the crack (`CRK`) and the sun flare (`P.sun`). Also `keyLight()` and `palTick()`, which read `P.sun`, `P.wheel` and `P.dayCyc`.
7. **`step()`:** story-specific clocks (`G.swirlT` boost, `dayCyc`, `wheelA`). **`finishStory()`:** `sfx('finale')`.
8. **Preview line:** the 试听 button speaks `CUES[1]`, so keep a narration line at index 1 (the prologue) or change the `o-test` handler.

9. **Props:** every prop a cue brings in needs a later cue that takes it away (set it to 0). Check this while writing `CUES`, then again in the screenshots.
10. **Sky-body positions vs overlays:** keep the sun and moon clear of the top overlays (checklist, fact box, counter). In example 02 the sun first sat behind the checklist bar.

## Writing it without hitting the output limit

Writing a whole page in one go hit the output-token limit. Instead:
- copy the template;
- replace one section per Edit (roughly 300 lines at most per call), starting with the text parts (`CARDS`, `CUES`), then drawing, then events;
- run `tools/check_syntax.py` after each Edit.

**For big sections, write files and splice them in** (this worked for example 02, which had about 1,400 new lines of scene code):
- Write each new section to a scratch file with the Write tool, 300 lines or fewer per file, several files per section if needed.
- Concatenate them and replace the old section in one step by its section-comment markers: `python tools/splice.py page.html "<start marker>" "<end marker>" new.js`.
- For example 02 that meant five scene files (landscape, people and disaster, forge and diagram, graphics, character) replacing everything from `大鸡蛋` up to `纪录片的文字画面`, one file for the cues, one for the effects, and one for the timeline and frame loop.
- Fix-ups afterwards go in a small Python script of exact `replace(old, new)` pairs that asserts each old string occurs exactly once. Write it with the Write tool, not a heredoc, if it contains backslashes.

**Or rebuild the whole page from section files every time** (one build did about 40 rebuilds): `python tools/build_page.py spec.json`.
- The spec names the template, the page, the text replacements (title, start and end screens, storage prefix), the sections as `[start marker, end marker, [files]]`, final replacements, and the recordings folder. The tool's header shows the format.
- A typical set of sections, in order: `色调: 每个场景一套` → `章节卡` (palettes); `章节卡` → `配乐：` (cards, cues, `P0`, `G`); `配乐：` → `旁白：` (example 03's music with the new story's `SFX` and `ambTick`); `色调的过渡` → `大鸡蛋` (palette blending, background, post); `大鸡蛋` → `纪录片的文字画面 (DOM)` (nine scene files); `时间线` → `字幕` (timeline and frame loop). Plus one final replacement: `resize(); initParticles(); applySub();` → `resize(); applySub();`.
- Fix-ups become exact replacements on the section files, then a rebuild. Nothing is ever spliced twice, and once the recordings exist, every rebuild re-embeds them.

## Engine additions in example 02 (copy them when needed)

These live in `example/02-女娲造人与补天-无录音.html`. Grep the names.

- **Word events can change pose, music and palette.**
  - `fireEv` accepts `pose`, `pd` (pose duration), `mood` and `pal` in an event's third item.
  - `stateAt` replays them when jumping. Without this, a jump lands on the wrong pose or music.
  - `applyK` and `stateAt` skip keys that aren't in `P0`. Otherwise `pose:'shape'` would create a junk `P.pose`.
  - Use it for anything tied to a word, like the music switching to *joy* on 「活了」.
- **Mood of a cue that changes mid-line:** give the event its `mood`, and don't set the same `mood` again on the next cue. `setSection` restarts a section even when the name is the same.
- **`resolveTarget(v, fallback)`:**
  - `'@c'` targets (the clay figure) join `'@h'` (the head);
  - a missing target keeps the current value instead of snapping the camera to 0;
  - `claySync()` computes the figure's position in `startCue` and `stateAt`, before `'@c'` targets are resolved.
- **Far-layer parallax:**
  - `withFar(f, fn)` draws the sky, clouds and far mountains with only part of the camera's zoom, anchored to the horizon: `f` .25 for the sky, .5 for the mountains.
  - `farScreen()` gives their screen positions, used by the sun's lens flare and by `keyLightScreen()` for the background glow.
  - Why: without it, a 2.2× close-up blew the mountains up into beige blobs filling the top of the frame.
- **Sky gradient anchored to the horizon:** `drawBG()` places `bg0 → bg1 → bg2` around the horizon's screen position instead of the screen's top and bottom. Before, close-ups showed the darkest zenith colour between the peaks, like holes in the sky.
- **Counters driven by values:**
  - `watchers()` in `step()` compares `floor(P.row)`, the arrived stones and `floor(P.pillars)` with the last value it saw, and calls `showStat` plus a sound when one grows;
  - `stateAt` sets the last-seen values so a jump doesn't set off a burst of sounds;
  - `showStat` then swapping in text (「数不清」) ends a counter on a word.
- **`label(zh, en, at)`:** a label that appears on a word, called from `EV`.
- **Ambience loops that follow the scene:**
  - `loopTo(name, gain, make)` inside `ambTick()` keeps looping rain, pour and fire sounds at `P.rain` and similar levels;
  - they follow jumps and pauses without any start or stop calls;
  - one-off crackles and birds come from a timer.
- **The atmosphere canvas has one composite point:** `ax` is drawn onto the main canvas once, partway through `render()`. Anything drawn into `ax` after that point never shows, which is how the example 02 fire glow first went missing. Draw late glows onto `g` with `'lighter'`.
- **`avoidRiver(x, d, margin)`** pushes houses, people, fields and trees off the winding river. Before it, randomly placed huts landed in the water.

## Engine additions in example 03 (copy them when needed)

These live in `example/03-神农尝百草-无录音.html`. Grep the names. Example 03 also has example 02's word events that change pose, music and palette, plus `resolveTarget(v, fallback)`, `hush`/`unhush` and `label()`.

- **Chapter-card dip:** `P.dim` is a black overlay drawn in `post()`. A card sets `dim:[.92,.8]`, cuts the camera and scene with `[value, .01, 1]` tweens, and un-dims with a timed event `[2.3, 'none', {dim:[0, 1.8]}]`. It needs the template's card events.
- **Mirroring:**
  - `P.snFace = -1` mirrors the character. The skeleton always faces right.
  - `mirCtx()` flips `g`, `gg` and `rx`. `snMir()` gives world positions for `G.head`, `G.handR`, `G.chest` and `G.hands`.
  - The key light is mirrored before the gradients are drawn.
- **Seated contact:** `seat` is a `PDEF` key. `extent()` blends toward resting the pelvis on the ground or a rock. Without it, cross-legged poses floated.
- **Several labels at once:** `label(zh, en, at, dur, dx, dy)` pushes onto `G.calls` (up to 3), each with its own offset. `calloutAnchor` knows leaf, root, basket, chest and drawers.
- **Pop icons:** `xIcon(k, zh, en, fx, fy, pop)`. With `pop` it draws a gold ring and no strike-through, meaning "here's a thing" rather than "no thing".
- **`fadeGlow(a)`** removes the glow canvas's content before a full-screen overlay (map, room). Without it, the rim light shone through as a ghost figure.
- **Counters:**
  - `count70` sets `statAnim.from = 1`. `watchers()` adds a puff every 5 counts and swaps the Chinese caption when the count finishes.
  - `ON.count300` runs `showStat(300, …, cueEst(cue) * .8)` so the count fits the spoken line. `c300end` swaps the text to 「三百多种」 on that word.
- **`ON` runs after `applyK`,** so a `k` tween on the same key would start from the old value. `ON.dayStart` sets `P.wheelA` itself, then starts its own tween.
- **A wide world** (about 12,000 units, one place per chapter): the key light follows the camera (`P.camX + P.lx`), and the sun is anchored to the camera (`camX * .25 + SUNP`).
- **`watchers()`** also handles map stops (from `P.route`), relay handoff sounds, and one-shot sounds for the child and the golden figure.
- **`stateAt()`:**
  - it resets `nameT mindT gulpT cureT breathT leafT breezeT pickT deepT bellT basketT gust icons calls puffs cnt c70 c300 trail fx stopT kidDone ghostDone`;
  - it recomputes `G.relayN`;
  - it rebuilds `G.stopT` from `P.route`.
- **Small patterns:**
  - `P.dCap` is an index set with a `.01` tween and rounded when drawn, which switches captions.
  - `P.picked` is a one-way hide flag, so an eaten plant never comes back.
  - `bgX` is the basket's absolute position on the ground.
  - `ambTick` scales its fire, water and wind loops by an `outside` factor, so they're silent in the room and on the map. The water loop only plays near the meadow (`nearMeadow()`).
  - `finishStory` fades the reminder card (`tip`) and `dim`.
- **`SECS.title` has `braam:.75`** (the template has 1). It was softened while levels.js still double-played the title; with the fixed tool, 1 is likely fine.
